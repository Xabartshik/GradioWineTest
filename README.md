# Веб-приложение на Gradio: Оценка качества вина (Регрессия с расширенной предобработкой)

Интерактивный диагностический сервис на базе Gradio для предсказания органолептической оценки качества красного вина (по шкале от 0 до 10) с использованием модели регрессии Scikit-Learn с расширенной предварительной обработкой данных. Проект обучен на основе датасета UCI Wine Quality Dataset (1599 образцов красного вина).

---

## 1. Повышение метрики качества (R²) с помощью предварительной обработки данных

Базовая линейная регрессия без преобразований показывала коэффициент детерминации R² = 0.4032 (на тесте) и R² = 0.3425 (на кросс-валидации).

Для повышения качества предсказания (R² на отложенном тесте повышен до 0.4420, кросс-валидация R² повышена до 0.3803) был реализован конвейер предварительной обработки:

1. Категоризация и One-Hot кодирование (OneHotEncoder через ColumnTransformer):
   * Ключевые показатели вина разбиты на смысловые физико-химические диапазоны:
     - alcohol_level (низкий, средний, высокий алкоголь);
     - volatile_acidity_level (чистое брожение, умеренная кислотность, порок / высокая летучая кислотность);
     - sulphates_level (низкий, оптимальный, высокий уровень сульфатов);
     - ph_level (кислый, сбалансированный, низкокислотный).
   * Категории закодированы с помощью OneHotEncoder(handle_unknown='ignore', sparse_output=False), что позволяет модели улавливать нелинейные эффекты внутри интервалов.

2. Конструирование инженерных признаков (Feature Engineering):
   * free_to_total_so2: отношение свободного диоксида серы к общему (доля активного антиоксиданта);
   * sulphate_to_volatile: отношение защитных сульфатов к дефекту уксусной кислоты.

3. Нелинейная трансформация степеней (PowerTransformer, метод Yeo-Johnson):
   * Устраняет выраженную асимметрию и тяжелые хвосты в распределениях концентраций кислот, сахаров и солей, приближая их к гауссовскому виду.

4. Моделирование полиномиальных взаимодействий (PolynomialFeatures):
   * Попарные взаимодействия (degree=2, interaction_only=True) учитывают синергию компонентов (например, взаимодействие спирта с кислотами и антиоксидантами).

5. Стандартизация (StandardScaler) и L2-регуляризация (RidgeCV):
   * Автоматический подбор оптимального штрафа регуляризации предотвращает переобучение на коррелированных слагаемых.

## 2. Основные возможности приложения

1. Форма ввода параметров (11 независимых физико-химических признаков):
   * Спирт и плотность: объемная доля алкоголя (alcohol, % об.), плотность вина (density, г/см³).
   * Кислотный профиль: летучая кислотность (volatile acidity, г/дм³), лимонная кислота (citric acid, г/дм³), фиксированная кислотность (fixed acidity, г/дм³), водородный показатель (pH).
   * Консерванты и антиоксиданты: сульфаты (sulphates, г/дм³), свободный диоксид серы (free sulfur dioxide, мг/дм³), общий диоксид серы (total sulfur dioxide, мг/дм³).
   * Сахар и минерализация: остаточный сахар (residual sugar, г/дм³), хлориды / соли (chlorides, г/дм³).

2. Прогнозирование целевой переменной (quality):
   * Расчет числовой непрерывной оценки качества вина (например, 6.45 / 10).
   * Определение сомелье-категории качества: «Превосходное / Премиальное» (>= 6.8), «Качественное выше среднего» (5.7 - 6.7), «Стандартное столовое» (4.7 - 5.6), «Вино с дефектами» (< 4.7).
   * Подробное текстовое экспертное заключение с анализом букета и баланса.

3. Визуализация (Диаграммы рассеяния и линия регрессии):
   * Основная диаграмма: точки обучающей выборки с цветовой шкалой качества + линия регрессии с учетом предобработки + точка текущего образца пользователя, выделенная крупным маркером с выносной аннотацией.
   * Интерактивный выбор признака для оси X (alcohol, volatile acidity, sulphates, citric acid, total sulfur dioxide, density).
   * Бонус: Мульти-диаграмма рассеяния сразу для 4 ключевых признаков качества.

4. Метрики качества и уравнение регрессии в LaTeX:
   * Коэффициент детерминации: R² = 0.4420 (на тесте), R² = 0.3803 +- 0.0566 (5-Fold CV).
   * Ошибки регрессии: RMSE = 0.6039, MAE = 0.4867 балла.
   * Отображение на форме точного уравнения регрессии в синтаксисе LaTeX с округлением коэффициентов до двух знаков.

5. Заранее обученная и сохраненная модель:
   * Сериализованный конвейер сохранен в models/wine_model.joblib.
   * Модель загружается в память один раз при старте веб-сервера.

## 4. Инструкция по установке и запуску

### Создание и активация виртуального окружения

В терминале (PowerShell / Bash) перейдите в каталог проекта:

```powershell
cd "c:\Projects\Учёба\Магистратура\ЯПМО\Gradio"

# Создание виртуального окружения
python -m venv .venv

# Активация окружения (Windows PowerShell):
.\.venv\Scripts\Activate.ps1

# Либо в командной строке Windows (cmd.exe):
.\.venv\Scripts\activate.bat

# Либо в Linux/macOS:
source .venv/bin/activate
```

### Установка зависимостей

Установите необходимые пакеты из requirements.txt:

```bash
pip install -r requirements.txt
```

### Запуск веб-приложения

Запустите сервер Gradio командой:

```bash
python main.py
```
*(также поддерживается запуск через python app/app.py)*

После запуска откройте в браузере локальный адрес:
http://127.0.0.1:1477 (или http://127.0.0.1:7860 при запуске app.py).

## 5. Как загружать и использовать модель

Модель сохранена с помощью библиотеки joblib в виде конвейера sklearn.pipeline.Pipeline.

Пример использования модели в стороннем коде:

```python
import joblib
import pandas as pd
from app.model import prepare_input_dataframe

# Загрузка конвейера из файла
model = joblib.load("models/wine_model.joblib")

# Пример входных характеристик вина (одна строка)
raw_input = {
    'fixed acidity': 8.5,
    'volatile acidity': 0.28,
    'citric acid': 0.56,
    'residual sugar': 1.8,
    'chlorides': 0.055,
    'free sulfur dioxide': 15.0,
    'total sulfur dioxide': 35.0,
    'density': 0.9932,
    'pH': 3.30,
    'sulphates': 0.85,
    'alcohol': 12.8
}

# Добавление инженерных признаков и категорий для OHE
prepared_df = prepare_input_dataframe(raw_input)

# Вычисление прогноза качества вина
predicted_quality = model.predict(prepared_df)[0]
print(f"Оценка качества: {predicted_quality:.2f} из 10")
```

Для переобучения модели и обновления метаданных запустите:
```bash
python train_model.py
```

## 6. Примеры входных данных

### Пример 1. Премиальное выдержанное вино (Отличное)
* Алкоголь (alcohol): 12.8 % об.
* Летучая кислотность (volatile acidity): 0.28 г/дм³ (низкая, признак чистой ферментации)
* Сульфаты (sulphates): 0.85 г/дм³
* Лимонная кислота (citric acid): 0.56 г/дм³
* Плотность (density): 0.9932 г/см³
* Оценка модели: 6.95 / 10 -> Превосходное / Премиальное вино

### Пример 2. Стандартное столовое вино (Среднее)
* Алкоголь (alcohol): 10.0 % об.
* Летучая кислотность (volatile acidity): 0.52 г/дм³
* Сульфаты (sulphates): 0.60 г/дм³
* Лимонная кислота (citric acid): 0.25 г/дм³
* Плотность (density): 0.9968 г/см³
* Оценка модели: 5.62 / 10 -> Стандартное столовое вино

### Пример 3. Вино с дефектом (Низкое качество)
* Алкоголь (alcohol): 9.2 % об.
* Летучая кислотность (volatile acidity): 0.95 г/дм³ (избыток уксусной кислоты)
* Сульфаты (sulphates): 0.45 г/дм³
* Лимонная кислота (citric acid): 0.05 г/дм³
* Плотность (density): 0.9985 г/см³
* Оценка модели: 4.54 / 10 -> Низкое качество (Вино с дефектами)

## 7. Форматы используемых файлов

* .joblib (models/wine_model.joblib): бинарный сериализованный объект обученного конвейера Scikit-Learn.
* .json (models/model_info.json): файл метаданных с метриками (R², RMSE, MAE), уравнением регрессии в LaTeX, диапазонами и весами признаков.
* .csv (data/winequality-red.csv, data/train_data.csv): табличные данные исходного и рабочего датасета для построения фоновых точек диаграмм рассеяния.
